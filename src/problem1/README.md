# Problem 1 - Written answers

## Question 1

Accounting changes calculation rules, the presentation team changes invoice layout, and IT changes storage. Invoice therefore has three main reasons to change.

## Question 2

The total, printed totals and saved text change because they depend on subtotal(). With the discount, the subtotal becomes 8740 MAD and the total becomes 10488 MAD. Individual item prices stay unchanged. This shows fragility: one change affects other outputs.
